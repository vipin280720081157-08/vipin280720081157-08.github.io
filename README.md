# Vipin T K — Portfolio

A responsive, single-page personal portfolio built with HTML, CSS and vanilla JavaScript. Designed for deployment with GitHub Pages.

## Deploy with GitHub Pages

1. Create a **public** GitHub repository named exactly `vipin280720081157-08.github.io`.
2. Upload `index.html`, `css/`, and `js/` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. After publishing, visit: https://vipin280720081157-08.github.io/

## Before publishing

Review the content and update any skills or project descriptions that do not accurately reflect your experience. The portfolio uses Google Fonts; the page still works with fallback fonts if they cannot load.

## Files

- `index.html` — page content
- `css/style.css` — responsive styling
- `js/script.js` — mobile navigation and current year
